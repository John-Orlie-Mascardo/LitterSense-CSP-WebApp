> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not delegate this plan unless the user explicitly enables agent delegation.

**Goal:** Repair the nine-item QA batch without changing behavior thresholds, classifications, or locked state descriptions.

**Architecture:** Focused Firebase Storage helpers own upload lifecycle and cleanup; one typed Recharts component owns every owner-facing trend axis; pure History helpers own filter/group behavior while a route hook owns bounded Firestore reads. Reconcile the committed `CatContext` merge regression before validating dependent photo and History behavior.

**Tech Stack:** Next.js 16, React 19, TypeScript, Firebase Auth/Firestore/Storage, Recharts 3, Tailwind CSS 4, Node test runner.
